Mac Tools

Native macOS utilities that bring scattered system controls into one place. Each tool replaces or improves a built-in macOS feature — built with Swift and SwiftUI, designed to feel like they belong on the platform.

macOS provides the pieces but spreads them across menus, widgets, and Control Center. These tools consolidate related controls into focused, single-purpose interfaces that live in the menu bar.

4 tools released · more in development

MediaBar

A native macOS application that turns the MacBook notch into an ambient media controller. Detects whatever is playing — Spotify, Apple Music, YouTube in any browser, Audible, Podcasts, Apple TV — and exposes track info, artwork, and controls in a pill that sits flush with the hardware notch.

LookingGlass

A menu bar app that turns the built-in camera into an ambient mirror. Hover for a passive preview, click for a full popover with a shutter, capture straight to Photos with iCloud sync. Privacy-first Photos integration: declares only the add-only permission so the system itself enforces that the app cannot read your library.

Battery Hub

A menu bar utility that replaces the native macOS battery icon. Shows battery levels for your MacBook and all connected Bluetooth devices — AirPods, mice, keyboards, controllers — in a single click. Supports ring and list layouts, customisable display options, and Low Power Mode toggling.

FocusFlow

A menu bar focus timer that controls your environment. Starting a session activates Do Not Disturb, hides distracting apps, and optionally enables background sounds. Tracks focus sessions with streaks, weekly charts, and session history — all without leaving the menu bar.

Technical Approach

How these are built

Shared principles

Every tool in this series is built natively with Swift and SwiftUI — no Electron, no web wrappers. They use platform APIs directly (IOKit, IOBluetooth, AppKit) and are designed to feel indistinguishable from system utilities. Each tool lives in the menu bar, respects dark/light mode, and is focused on doing one thing well.

What varies

Each tool engages different system APIs and interaction patterns. Battery Hub uses IOKit power source notifications and Bluetooth device enumeration. FocusFlow uses NSWorkspace for app lifecycle management, Apple Shortcuts for Focus mode automation, and Combine-driven timer state propagation. MediaBar reaches further into the system — the private MediaRemote framework via a vendored Perl bridge, AppleScript control of Spotify and Apple Music, and AppleScript JavaScript injection to track live <video> position inside browser tabs. LookingGlass works through AVFoundation for camera capture and Photos with the add-only authorization scope, paired with a Carbon hot-key bridge for the system-wide shortcut.
